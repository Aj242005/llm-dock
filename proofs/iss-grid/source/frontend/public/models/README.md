# ISS model

NASA source: https://science.nasa.gov/resource/international-space-station-3d-model/

Usage guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/

Downloaded stationary glTF model, optimized locally with glTF Transform 4.5.1. Geometry is not simplified; named module nodes are preserved. Meshopt compression and 1024 px WebP textures reduce the download from 44.5 MB to 5.6 MB. SHA-256 hashes and the alignment transform are in `iss-source.json`.

NASA is acknowledged as the asset source; no endorsement is implied. The PMA-2 forward port is the visual origin. The ISS geometry is visual context, not a collision mesh or flight hardware model.
